# Как выложить сайт

Два пути. Оба не требуют передавать кому-либо пароли.

---

## Путь A. GitHub Pages — бесплатно, обновляется само

Репозиторий уже есть, сборка настроена, файл `CNAME` с доменом на месте.
От вас три действия.

### 1. Слить ветку в main

На странице репозитория: **Pull requests → New pull request**,
из `claude/church-website-premium-design-fdvjdi` в `main`, **Merge**.

Если ветки `main` ещё нет — Settings → Branches, либо просто переименуйте
рабочую ветку в `main`.

### 2. Включить Pages

**Settings → Pages → Build and deployment → Source: GitHub Actions.**

После этого при каждом изменении сайт пересобирается и публикуется сам.
Первая сборка займёт минуту-две.

### 3. Направить домен

В панели регистратора `lttw.ru` пропишите записи:

```
A      @      185.199.108.153
A      @      185.199.109.153
A      @      185.199.110.153
A      @      185.199.111.153
CNAME  www    lttwru.github.io
```

Затем в **Settings → Pages → Custom domain** впишите `lttw.ru` и поставьте
галочку **Enforce HTTPS** (появится через несколько минут, когда выпустится
сертификат).

DNS обновляется от получаса до суток. Пока не обновился, сайт доступен по
адресу вида `lttwru.github.io/LTTWsite`.

## Путь B. Обычный хостинг — архив

1. Соберите архив:

   ```bash
   node build.mjs && cd dist && zip -r ../lttw-site.zip . && cd ..
   ```

2. В панели хостинга распакуйте **содержимое** архива в папку сайта —
   обычно `public_html` или `www`. Не саму папку, а то, что внутри.

   Папка может быть любой: сайт собран на относительных путях и работает
   и в корне домена, и в подпапке вида `lttw.ru/LTTW/`, и просто на диске,
   если открыть `index.html` двойным щелчком. Проверено во всех трёх
   случаях.

3. В настройках сайта укажите страницу ошибки 404 → `404.html`.

4. Направьте домен на хостинг по инструкции провайдера.

Файл `CNAME` в корне нужен только для GitHub Pages. На обычном хостинге он
ничего не делает и не мешает — можно оставить или удалить.

**Обновление** потом: пересобрать, залить заново. Или прислать мне правки,
я соберу новый архив.

---

## Что настроить в любом случае

- **Редирект `www.lttw.ru` → `lttw.ru`** (или наоборот — главное выбрать
  одно). Иначе поисковики считают их разными сайтами и делят вес.
- **HTTPS.** На GitHub Pages включается галочкой, на хостинге обычно
  бесплатным сертификатом Let's Encrypt в панели управления.

## Почему я не могу выложить сам

Среда, в которой я работаю, выпускает наружу только HTTPS на порт 443.
Порты 21 (FTP) и 22 (SFTP) закрыты на сетевом уровне — проверено на
заведомо работающих серверах. Подключиться к хостингу я не смогу даже
с паролем.

И отдельно: пароли от хостинга не стоит присылать в переписку — они
остаются в истории чата насовсем. Если нужен помощник для выкладки,
заведите на хостинге отдельного FTP-пользователя с доступом только к
папке сайта и удалите его после.
