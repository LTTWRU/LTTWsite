# Шрифты

## Jost — подключён

`jost-cyrillic.woff2`, `jost-latin.woff2`, `jost-latin-ext.woff2` — вариативный
Jost, разбитый на юникод-сабсеты. Лежит локально, а не тянется с Google Fonts:
так сайт не зависит от внешнего CDN и грузится быстрее. Всего ~54 КБ, из них
на кириллической странице реально скачивается только ~10 КБ.

Лицензия: SIL Open Font License 1.1 — коммерческое использование разрешено.

## Federov2 — нужно добавить

Брендбук назначает **Federov2-Regular** основным шрифтом заголовков. Это
несвободная гарнитура, поэтому в репозитории её нет.

Чтобы заголовки поехали на Federov2:

1. Получите файл `Federov2-Regular.ttf` (или `.otf`) у дизайнера, который делал
   брендбук.
2. Сконвертируйте в `woff2` — например, на https://transfonter.org
   (обязательно включите кириллический диапазон).
3. Положите результат сюда под именем **`Federov2-Regular.woff2`**.

Больше ничего делать не нужно: `@font-face` для Federov2 уже описан в
`assets/css/style.css`, и заголовки переключатся автоматически. Пока файла нет,
браузер молча падает на Jost — вёрстка от этого не ломается, потому что обе
гарнитуры геометрические и близки по пропорциям.
